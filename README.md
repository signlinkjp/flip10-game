# LINEZAP

好きな2マスを入れ替えて、行か列の合計を**目標の数字**にそろえて消す1人用パズル。
HTML / CSS / JavaScript（素の ES Modules）＋ Capacitor 8 の iOS アプリ。**Build 7**（1.0.1）。

![home](../downloads/linezap-b5-home.png)

## モード（2つ）

ホームに並ぶのは **クラシック** と **タイムアタック** の2つだけ。
どちらも押すと**開始前ページ**が開き、**マス数**と**目標の数字**を選んでからスタートする
（タイムアタックは**時間**も選ぶ）。

| モード | 中身 | マス数 | 無料 / PRO |
| --- | --- | --- | --- |
| **クラシック** | 好きな2マスを入れ替える（ドラッグ / タップ2回）。手数と制限時間で遊ぶ | 4×4・5×5・6×6 | 4×4 は無料。**5×5・6×6 は PRO** |
| **タイムアタック** | 60秒 / 120秒 / 180秒の全体タイマーでスコア勝負。手数もターンタイマーも無い | 4×4・5×5・6×6 | **4×4・60秒だけ無料**。120秒・180秒と 5×5・6×6 は PRO |

Build 5 で十字フリップ（＋の字が反転・表裏で5）は遊び方から外した。UI・あそびかた・PRO の説明・
12言語の辞書からも消してある（2マス入れ替えのルールに一本化）。

## ルール（3秒でわかる）

1. **1マス目を押したまま、入れ替えたいマスまでドラッグ**して離すと、2つが入れ替わる。
   **タップ → タップ**でも同じ（同じマスをもう一度押すと選び直し）。1回の入れ替えで **手数 −1**。
2. 右側に**各行の合計**、下側に**各列の合計**が **`今の合計/目標`**（例 `9/10`）で出る。
   設定の「ヒント」を OFF にすると分子が **`？/10`** になり、暗算で遊べる（分母の目標は常に表示）。
3. 行か列の合計が**目標**とぴったりになると、そのラインが金色に光って消え、
   上から新しい数字が落ちてくる。連鎖はコンボで得点アップ。
4. **手数と制限時間**（クラシック）:
   - 手数は **4×4 が4 / 5×5・6×6 が5** からスタート。1手で −1。
   - 消すと回復する: **1ライン +1**（−1 と合わせて減らない）／**2ライン +2**（実質 +1）／
     **3ライン以上か連鎖で全回復**。
   - **1ライン以上消すたびに制限時間が戻る**（4×4 **10秒** / 5×5 **12秒** / 6×6 **15秒**）。
     入れ替えとコンボ演出の間は**タイマーを止める**ので、残り0.15秒でコンボが始まっても
     演出中に時間切れにならず、コンボのあと**タイマーが満タンに戻って続行**する（Build 6）。
   - 制限時間が **0秒** になると、**手数が残っていてもゲームオーバー**（リザルトに「タイムアップ！」）。
   - プレイ画面上部に残り秒数のバーと秒数（小数1桁）。**残り3秒以下で赤く警告**。
5. **ヒントは手数 −2**（クラシック）。残り手数が **3以上**のときだけ使え、
   2以下で押すと「ヒントは手数2つ。残り3以上で使えます。」のトーストが出る。
   タイムアタックは手数を持たないのでヒントはタダ。9秒操作がないときの自動ヒントは手数を減らさない。
6. **タイムアタック**は全体の 60秒 / 120秒 / 180秒だけで遊ぶ。0秒で終了。

得点は `100 × ライン数 × コンボ（連鎖段数） × 連続消し（最大5）`。

### 消える合計と基準目標（開始前ページで選ぶ）

| 盤面 | 目標の範囲 | 基準目標（ボタンに表示・初期値） |
| --- | --- | --- |
| 4×4 | **10 固定** | 10 |
| 5×5 | **12〜42** | **18** |
| 6×6 | **12〜42** | **24** |

サイズボタン（`4×4` / `5×5` / `6×6`）の中に **「基準 10」「基準 18」「基準 24」**（12言語対応）を出している。
**クラシックの開始前ページは、いつもそのサイズの基準数から始まる（Build 7）**。
前のバージョンで選んだ値や、古い Build が localStorage に書き残した値（5×5 に 13、6×6 に 18 など）には
引きずられない。開始前ページのステッパー（12〜42）はその場で使えるが、次に開いたときはまた基準数に戻る。
タイムアタック（とリザルトの「もう一度」）は、選んだ目標をそのまま使う。

設定画面の「消える合計」ステッパーは Build 4 で無くした（開始前ページに一本化）。

### 数字の出し方（スマートプール）

| 盤面 | 合計 | 出す数字 |
| --- | --- | --- |
| 4×4 | 10（固定） | 0〜6 |
| 5×5 | 18（基準） | 0〜7 |
| 5×5 | 42 | 5〜9 |
| 6×6 | 24（基準） | 1〜7 |
| 6×6 | 42 | 4〜9 |

`target / 盤面サイズ` の平均まわり ±3 で範囲を決め（`digitPool`）、盤面を作るときは
その平均を頂点にした山なり分布で出す（`poolFor` の `center` / `bell`）。
だから平均 2〜7 の数字が自然に作れて、目標 12〜42 のどこでも「1手でそろえられる」盤面になる。
盤面は「最初から消えていない」「必ず1手ある」状態で作る（`makeBoard` / `ensurePlayable`）。

### ベストスコアの分け方

`classic4` / `classic5` / `classic6`、タイムアタックは
`time60` / `time120` / `time180`（4×4）と `time5x60` / `time6x180` のように **サイズ×時間** で分ける。
4×4 のキーは Build 4 の記録をそのまま引き継ぐ。

## 数字タイルの色

0〜9 を色で見分けられるよう、**Build 5 で背景グラデーションを少し濃く**した
（青・シアン・ミント・ライム・黄・橙・桃・紫・青紫・赤）。文字は濃い紺のままなので、
明るい画面の雰囲気を保ちながら、隣り合う数字がひと目で区別できる。

## 画面と設定

- **初回起動のオープニング**: `LINEZAP` ロゴと黄金ラインが「パチッ」と光る 1.6秒の演出。
  **画面タップで即スキップ**。演出が終わるとホームへ。
- **明るいポップなライトテーマ**（空色〜クリームの背景・白い数字カード・紺の文字）
- **文字サイズ** 標準 / 大きめ / 特大（設定。375px でもはみ出さない）
- **プレイ画面の左上に ← は無い**（戻るは下部の「ホームへ」だけ。Build 4 で削除）。ヘッダーは スコア / ベスト / 手数 / 設定。
- **BGM は Build 3 から最初から ON**（`bgmDefault: 3`。ユーザーが OFF にしたら以降は尊重する）
- **プレイ中の ⚙️ 設定ボタン**と、設定シート（音・BGM・バイブ・ヒント・文字サイズ）
- **ヒント** ON/OFF（既定 ON）。ヒントボタンで消せる2マスがやさしく脈打つ。
- **バイブ（iOS Haptics）** ON/OFF（既定 ON）。選択 light / 入れ替え medium / ライン消去 success /
  コンボ2以上 heavy+success / ゲームオーバー error。
- **BGM のバックグラウンド漏れ対策**: `visibilitychange` / `pagehide` / `blur` で `AudioContext` を suspend、
  `AppDelegate.swift` でも `willResignActive` / `didEnterBackground` で JS を呼び、`AVAudioSession` を
  `setActive(false)` する（ホーム画面に BGM を残さない）。
- 設定・あそびかたを開いている間はタイマーを止める（ターンタイマーで理不尽に終わらない）。

## Build 7 の変更（トモアキさん要望）

1. **クラシックの基準数とスタート数の不一致を修正**。開始前ページは `storage.targetForStart()` を通り、
   クラシックは毎回 4×4=10 / 5×5=18 / 6×6=24 から始まる（`storage.targetFor()` は保存値をそのまま読むので、
   タイムアタックの「最後に選んだ目標」は今までどおり）。
2. **プレイ画面の目標数を大きく**。目標は盤面の上に大きなカード（数字は約3rem）で出し、
   右と下の合計は「今の合計」を大きく、「/目標」を少し小さくして1行に収めた（6×6 も折り返さない）。
   空いていた縦の余白に目標カードを置き、盤面を中心に保つ。
3. **ホーム画面のボタンを拡大**。あそぶボタン・モードカード・サイズの目印・下部の言語/PRO・右上の
   アイコンを大きくし、縦画面に収まるよう余白を配り直した（375px・特大文字でもはみ出さない）。

## Build 6 の修正（トモアキさん報告）

### 1. ゲーム中にフリーズする

- **入れ替えの `busy` を `try/finally` で必ず下ろす**（`doSwap`）。音・DOM・計算のどこで失敗しても
  以後のタップとドラッグが効かなくなる状態を残さない。
- **時間切れの終了処理（`endRun`）に `try/finally`**。音（`audio.over`）やバイブ、結果の書き込みが
  失敗しても **結果シートは必ず開く**。同じゲームの終了処理は1回だけ（`state.endRunFor`）。
- **見張り番（0.25秒ごと）**: `busy` が6秒たっても戻らなければ操作を解放し、
  「終わっているのに結果シートが出ていない」状態なら結果シートを開き直す。
  逆に「続行中なのに結果シートが残っている」なら閉じる。
- **ドラッグの取り残し対策**: `pointercancel` / 画面遷移 / 時間切れ / アプリが裏に回ったときに
  `state.drag` を捨てる。ドラッグ直後の `click` は**時刻**で捨てるので、次のタップを飲み込まない。
- タイマーの刻みは最大1秒（端末が固まって戻ったときに、まとめて0秒にならない）。

### 2. 残り時間ギリギリのコンボで時間を復活させる

- **演出中は時計を進めない**（`core.canTickClock`）。入れ替え110ms＋コンボの段ごとに約0.6秒の間、
  残り時間は減らない。止めている間の時間は復帰時にまとめて引かない（`lastTick` を進める）。
- **ラインが消えた手は時間切れより優先**（`core.mergeMoveResult`）。演出中に0秒になっていても、
  コンボが成立していればクラシックのターンタイマーは満タンに戻って続行する。
  コンボ不発の入れ替えは、時間切れを覆さない（0秒のままプレイが続かない）。
- タイムアタックは仕様どおり全体タイマーを戻さない（コンボの得点は入れてから終了）。
- 残り時間ギリギリからコンボで戻ったときは、タイマーバーが一瞬光る（`.turnbar.is-refilled`）。

```bash

python3 tools/make-icon.py    # アイコンを各サイズに書き出す
```

`/workspace/downloads/linezap-b6-*.png`（Build 6 の回帰）
（`-opening` / `-home` / `-start-classic` / `-start-time` / `-play` / `-play-6` / `-play-time` /
`-result-timeout` / `-howto` / `-settings` と 375px・特大の `-home-375-xl` / `-start-375-xl` / `-play-375-xl`）。

## TestFlight（Build 7）

1. `.github/workflows/ios-testflight-build1.yml`：ビルド番号（`CURRENT_PROJECT_VERSION`）は iOS プロジェクトから
   自動で読むので貼り替え不要。ただし **`MARKETING_VERSION` は 1.0.1 に上げる**（`env:` の
   `MARKETING_VERSION: "1.0.1"` と preflight の `assert 'MARKETING_VERSION = 1.0.1;' in pbx` の2か所）。
   `pbxproj` を 1.0.1 にしたので、ここが 1.0.0 のままだと preflight が止まる。貼り付け用の控えは
   `docs/ios-testflight-build1.yml`（1.0.1 に更新済み）。ワークフローの書き換えは GitHub App の権限外なので、
   トモアキさんの手元（GitHub の Web エディタ等）で入れる。
   古いガード（十字フリップの `PAIR_SUM = 5` 等）は `src/core.js` / `index.html` の互換メモで満たしている。
2. Actions →「LINEZAP iOS TestFlight」→ `confirm_bundle_id` に `jp.signlink.Flip10`、`upload_to_testflight` = true
3. App Store Connect: アプリ `LINEZAP`（`jp.signlink.Flip10`）と非消耗型 IAP `jp.signlink.Flip10.pro`
   （表示名 `LINEZAP PRO`・¥300 プレースホルダ）
   ※ Bundle ID と IAP 製品 ID は登録済みのため **変更しない**（表示名だけ LINEZAP）

ビルド番号は `ios/App/App.xcodeproj/project.pbxproj` の `CURRENT_PROJECT_VERSION`（Debug / Release 両方）で管理する。
